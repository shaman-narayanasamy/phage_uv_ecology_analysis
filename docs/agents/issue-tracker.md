# Issue tracker: GitHub

Issues and manuscript-readiness work for this repository live in GitHub Issues at `shaman-narayanasamy/phage_uv_ecology_analysis`. Use the `gh` CLI from this checkout.

## Conventions

- Read an issue and its discussion before acting.
- Create independently verifiable issues with explicit acceptance criteria and dependencies.
- Apply the appropriate workflow label from `triage-labels.md` plus relevant domain labels such as `manuscript`, `validation`, or `reproducibility`.
- Close an issue only after its acceptance criteria are evidenced in committed repository artifacts or an issue comment.
- Do not close or materially rewrite a parent issue while resolving a child issue.

When a skill says to publish or fetch a ticket, use GitHub Issues in this repository.
