# ISME Communications review package

Status: local researcher-authoring scaffold; not submission-ready.

This directory adapts the venue-neutral manuscript for an ISME Communications
Original Article submission. It is a review package, not a submitted package.
The canonical scientific draft remains
`manuscript/manuscript_skeleton.md`; this directory does not fork or silently
rewrite that text.

The live journal policy checked on 2026-09-01 prohibits LLM-drafted
manuscripts. Because the current prose began as an agent-authored draft, human
researchers must independently author the submitted text and approve the AI-use
disclosure. See `researcher_authorship_remediation.md`.

## Files

- `title_page.md`: provisional title-page metadata and unresolved author fields.
- `cover_letter_draft.md`: journal-specific cover-letter draft.
- `submission_checklist.md`: verified checks and remaining submission gates.
- `researcher_authorship_remediation.md`: mandatory human-authoring and AI-use
  disclosure gate for this journal.
- `prior_publication_metadata.md`: metadata recovered from the published study,
  kept separate from decisions that the authors must make for this manuscript.
- `submission_review_manuscript.md`: derived, journal-formatted author-review
  manuscript with numbered citations, references, figure previews, and alt text.
- `oxford-journals-scimed-numeric.csl`: the current official Zotero style used
  to render Oxford SciMed numbered references.

## Action boundary

No file in this directory may be uploaded, pasted into Google Docs, sent to an
editor, or entered into a submission system without the author's immediate
approval. The journal order is provisional and remains subject to author
review. The independently delegated 16S analysis remains outside this package
until issue #30 is resolved.
