## Revised paragraph

Raw sequencing data are available from the European Nucleotide Archive under PRJEB79569 (secondary study accession ERP163720). Analysis code, sample metadata, software versions and input/output provenance are versioned in the project repository and its manifests. The accompanying supplementary report contains Supplementary Figures S1-S10. Supplementary Table S1 records the physical-sample contract; Table S2 contains expression-model definitions, design matrices, filtering, normalisation and diagnostics; Table S3 contains the complete tested-feature differential-expression results. Post-model functional-category statistics, MAG gene-set statistics and recurrent-gene candidates are supplied in Tables S4, S5 and S6, respectively. Population-genomic source panels, taxonomic profiles and CRISPR-derived host-phage evidence are supplied in Tables S7, S8 and S9. Table S10 contains community-abundance results and their model-dependent sensitivities, and Table S11 contains the cDNA-derived 16S profiles and turnover summaries. These tables comprise 47 unchanged TSV files in source_data.zip; source_data_manifest.tsv identifies each file part, its source, column names, row count, size and SHA-256 checksum.
